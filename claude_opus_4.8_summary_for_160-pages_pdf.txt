## 0. The mission in one paragraph

Build **two symmetric autonomous agents — a Cop and a Thief — that play a pursuit game on a grid with NO central server/referee.** Each agent is *simultaneously a server and a client* over `FastMCP` (MCP protocol). Neither agent can see the true world state: each maintains a **Bayesian belief** about the opponent's location, built from (a) the opponent's **decaying scent trail** (biological stigmergy — cannot be faked) and (b) the opponent's **verbal hints** (natural language — *may be lies*). Integrity without a referee is guaranteed by a **cryptographic Commit-Reveal protocol** (SHA-256): any tampering is provably caught in a post-game audit and scores the cheater 0. The whole thing runs over the public internet (ngrok/Localtonet tunneling), in a live league against other groups' agents, and reports results as signed JSON via the Gmail API. You submit **two separate GitHub repos** (one Cop, one Thief).

The grade is decided by four things — **Coordination, Adaptation (scent-based), Integrity (crypto), and Architecture (Gatekeeper/Orchestrator)** — *not* by the cleverness of any single algorithm.

## 3. The Dec-POMDP model (needed for README component #1)

The environment is formally a **Decentralized Partially Observable Markov Decision Process**, the 8-tuple:

```
⟨ n, S, {Aᵢ}, P, R, {Ωᵢ}, O, γ ⟩
```

- **n = 2** — cop and thief (a single rational adversary, not random nature).
- **S** — full world state: exact coordinates of both agents + static barrier layout + the dynamically-changing scent grid. Multi-dimensional → brute-force enumeration is infeasible (this is *why* you use heuristics/learning).
- **{Aᵢ}** — actions: physical moves, build actions (placing barriers), and communication actions (natural-language hints, *which may be false*). Physics + psychology combined.
- **P** `P(s′ | s, a₁, a₂)` — transition function. Because there is no central server, **both sides must compute the same P — it is encoded in the shared config.**
- **R** — reward function, translated directly from the scoring table (§5).
- **{Ωᵢ}, O** — observations: the core uncertainty. Neither agent sees the other; each is fed only the opponent's **decaying scent trail** + the opponent's **verbal declarations**. This is what forces a probabilistic **belief map**.
- **γ** — discount factor ∈ [0,1); high γ rewards patient strategy (e.g. building a barrier trap over many turns).

You must describe your adopted Dec-POMDP (state space, observations, uncertainty) in each repo's README.

## 4. Board & physics (Ch3, Appendix F tables 13 & 15)

- **Grid:** 7×7 minimum. Cell = `(row, col)`. Origin `(0,0)` top-left (vertical axis grows downward), 0-indexed. So center of 7×7 is `(3,3)`, corner is `(0,0)`. Origin corner and index base are *negotiable but must be identical on both sides* — if one side counts from 0 and the other from 1, `(3,3)` won't match and the game breaks.
- **Start positions** (negotiable, must match): thief center `(3,3)`, cop corner `(0,0)` — example only; any legal agreed layout is allowed. Loaded from config, never hard-coded.
- **Movement (FIXED):** each turn an agent makes **one** move — step one cell **orthogonally (up/down/left/right) OR stay put**. **No diagonals** — a diagonal move is rejected by the opponent enforcing physics → technical loss.
- **Barriers (the cop's asymmetric power):** on a turn where the cop **forgoes moving**, it may place a barrier on **any cell within one step — the cell it stands on, or one of the 4 orthogonally-adjacent cells**. The barrier cell becomes **impassable for BOTH players until the end of the game** (irreversible). Quota = **14 minimum**.
  - **Capture-by-barrier:** if the cop places a barrier on the cell the thief currently occupies → **thief captured (cop wins).**
  - **Jailed thief:** a thief with **no legal move** (all adjacent cells blocked by barriers and/or board edge) → **also counts as captured.**
  - **Mandatory truthful declaration:** the cop must openly declare every barrier placement and its exact location. No hidden barriers; lying about a barrier location = severe disqualification (caught in audit).
  - Barriers are a resource-management problem: don't wall yourself in or open a new escape lane for the thief.

## 5. Stigmergic scent map (Ch4, Appendix F table 16 — all FIXED)

Biological ant-pheromone coordination. **Both agents emit scent; each reads only the opponent's trail.** Scent is emitted automatically by moving/staying and **cannot be faked** — this is what exposes verbal lies.

- **Emission:** whenever an agent moves or stays, a scent field of size **5×5** forms around it. Center cell (the agent's position) gets intensity **0.9**; intensity falls off radially with distance (near cells high, edge cells a faded remnant). Concentrated fingerprint, not a single point.
- **Decay:** after every *full* turn (both agents have moved), all scent on the board decays. Decay rate **ρ = 0.10** per turn. Update rule for cell `(i,j)`:

```
τ_ij(t+1) = max(0, (1 − ρ)·τ_ij(t) + Δτ_ij)
```

  where `τ_ij(t)` ∈ [0, 0.9] is current intensity (a local certainty score — high = the opponent was here recently), `Δτ_ij` is new emission this turn (0.9 at center, radial falloff, 0 if the agent is far), and `max(0, ·)` keeps it non-negative. `(1−ρ)` = *forgetting* (shrinks old scent to 90%); `Δτ` = *memory* (writes the present).
- **Practical consequence:** with ρ=0.10 a single deposit stays "readable" for ~6–7 turns before dropping below half-peak. That's the tactical window.
- **Lie detection (the payoff):** each agent cross-references the opponent's scent map against the opponent's verbal hint. Example: the thief says "I moved north," but the entire scent mass sits in the south-east and the north reads τ=0.00. Expected fresh trail in the north would be ≈ 0.9·0.9 ≈ 0.81; measured 0.00. The cop concludes (high confidence) the thief lied, lowers the trust weight on verbal hints, and steers toward the real scent source. The manipulation backfires.
- **RULE 23:** the scent emission+decay model must be **cryptographically locked before each series** — both groups exchange the full formula + a concrete numeric example, verify identical interpretation, then hash it (e.g. SHA-256 of formula+example). Any later deviation is detectable and voids the game. (You may even share the scent-mechanism code between groups to guarantee identical behavior.)

## 6. Bayesian belief map (Ch6 — needed for README component #3)

This, plus move selection, is where the agent's intelligence lives.

- Each agent maintains a **belief matrix** `b(s) = P(opponent = cell s)` over the whole grid (the cop's belief is over the thief; the thief holds a symmetric belief over the cop; barrier cells have zero belief).
- On each incoming observation, apply **Bayes' rule** to update `b(s)` from the two evidence sources: the (unfakeable) **scent map** and the (possibly-false) **verbal hint** — combined into a posterior. The scent likelihood is trustworthy; the hint's weight should be discounted when it contradicts the scent.
- **Move policy** (the graded core) minimizes/maximizes **Manhattan distance** (orthogonal grid) to the arg-max belief cell:
  - **Cop:** move to minimize Manhattan distance to `arg maxₛ b(s)` (chase the most-likely thief cell); when blind, drop a barrier.
  - **Thief:** move to maximize distance from its believed cop cell (flee toward open space).
- Allowed policy families (your choice, stated in the README):
  1. **Pure heuristic** — `Bayes + Manhattan` (transparent, zero-token, robust). You can even skip Bayes and just chase the strongest scent cell.
  2. **LLM-mapped policy** — the LLM outputs a move (risky; see rule 25 — blind reliance causes hallucinated illegal moves → loss).
  3. **Q-Learning / Bellman** — *optional*, for groups that want RL; include learning curves in the README if used.
- The belief map is displayed as a **heatmap in the live GUI** (a required screenshot).

## 7. Commit-Reveal cryptographic protocol (Ch5, Appendix E group 3)

This replaces the referee. In a refereeless P2P game there are three cheats to kill: **time-travel** (change a done move), **change-after-seeing** (adapt after the opponent reveals), and **denial** (disown a past move/claim). The fix is mathematical, not social.

**Every game step, each agent runs 4 crypto stages, in order:**

1. **Commit** — choose the physical move + the hint to send (including an `Intent` flag = is the hint `truth` or `lie`), draw a fresh **Nonce**, hash everything into a single digest, and send **only the digest `H_commit`** (not its contents):

```
H_commit = SHA256( State ‖ Move ‖ Intent ‖ Nonce )
```

   `‖` = byte concatenation. In the reference impl this is done via **canonical JSON** (`sort_keys=True`, fixed separators) so both peers hash byte-identical input. The real sealed record is richer than these four fields — it also includes the verbal hint, intent class, step number, and role.
2. **Acknowledge** — the opponent confirms receipt and locks onto the commitment (prevents the sender from retracting; ensures reveal happens only after both sides have locked).
3. **Reveal** — send the `Move` + the hint sentence. **The Nonce stays hidden** (prevents reverse-engineering the signatures prematurely).
4. **Final Audit** — **only at the end of the whole game** are all Nonces revealed, for full mutual verification.

**Nonce** (number-used-once): a fresh random string per commitment. It (a) makes repeated identical actions hash differently and (b) defeats a dictionary attack on the small move space. **Keep it absolutely secret until the final audit** (rule 18).

**Reference implementation:**

```python
import hashlib, json, secrets

def commit(state: str, move: str, intent: str) -> tuple[str, str]:
    nonce = secrets.token_hex(16)                       # cryptographic nonce
    payload = json.dumps(
        {"state": state, "move": move, "intent": intent, "nonce": nonce},
        sort_keys=True, separators=(",", ":"),          # CANONICAL JSON
    )
    h_commit = hashlib.sha256(payload.encode("utf-8")).hexdigest()
    return h_commit, nonce                              # send h_commit now; keep nonce secret

def verify(state, move, intent, nonce, h_commit) -> bool:
    payload = json.dumps(
        {"state": state, "move": move, "intent": intent, "nonce": nonce},
        sort_keys=True, separators=(",", ":"),
    )
    recomputed = hashlib.sha256(payload.encode("utf-8")).hexdigest()
    return secrets.compare_digest(recomputed, h_commit)  # any mismatch = tampering
```

Use `secrets` (not `random`) and `secrets.compare_digest` for the comparison.

**Mutual audit & the iron law (rules 19–22):** at game end each side re-hashes the opponent's revealed `(State, Move, Intent, Nonce)` and compares to the originally-committed `H_commit`. **Any mismatch = provable forgery = technical loss (score 0) for the cheater, regardless of the board result.** SHA-256 is bit-sensitive; there is no statistical doubt. You **must build a replay-viewer app** that steps through the log and verifies this chain, showing **"Verified OK"** (rule 20; required screenshot).

- On **HTTP 429**: back off and wait for the next window — never retry blindly (risks account suspension).
- **Three distinct meanings of "token"** — don't conflate: *rate tokens* (bucket), *LLM tokens* (metered + locked in Step-0), *OAuth tokens* (Gmail auth).

## 14. The 7-stage development roadmap (Ch10 — build in this order)

**Build in layers; each stage runs end-to-end before the next is added. One PRD file per stage.** Skipping foundations (e.g. jumping to crypto before the network is proven) makes every bug a multi-variable investigation.

1. **Base Logic** (Ch3) — grid (7×7), movement rules, barrier quota, coordinate-overlap capture. **Single process, no networking, no AI.** If two agents can't move correctly on a local board, networking is pointless.
2. **Basic FastMCP infrastructure** (Ch2) — split into separate processes; stand up the servers; tools exchange **pure numeric geometry over localhost**. Goal: prove the pipe works (a message from one agent reaches the other) before loading complex content.
3. **Blind strategy** (Ch6) — wire an initial decision module on **full, exact information** (no scent/language/deception yet): heuristic (Manhattan / Bayesian belief), LLM-mapped policy, or optional Q-Learning/Bellman. Isolates decision-core correctness from uncertainty noise.
4. **Language + Scent** (Ch4 + Ch6) — **the big leap.** Replace rigid coordinates with **free-language** reporting; implement the **pheromone emission/decay equations**; plug the **LLM in for inference + lie-crafting**. This is where the project's core uncertainty is born; it comes only after infra + logic are proven.
5. **Cloud + Tunnel** (Ch2) — move from localhost to **public addresses via ngrok/Localtonet**; connect agents on remote machines. Now it's a real distributed system (latency, disconnects).
6. **Security + Crypto** (Ch5) — wrap the proven remote comms in **Commit-Reveal**, write the **Nonce generator**, add **Step-0 hardware declarations**. Crypto sits *on top of* comms already proven reliable — so a failure is never ambiguous between "network" and "crypto".
7. **Reporting + Visualization shell** (Ch9 + Ch7 + Appendix A) — **Gmail API over OAuth 2.0**, finish the **GUI**, polish the **Replay app**. Built last because it consumes every layer beneath it.

*(The reference repo demonstrates local versions of stages 1–4 and 6–7.)*

- **shared** — config manager, rate-limiter, system-info, version.

Minimal server skeleton (each agent runs its own):

```python
from fastmcp import FastMCP
mcp = FastMCP("police_thief_peer")

@mcp.tool
def receive_move(signed_move: str, signature: str) -> dict:
    """Opponent (as client) submits a cryptographically signed move; verify before accepting."""
    is_valid = verify_signature(signed_move, signature)
    return {"accepted": is_valid, "move": signed_move if is_valid else None}

if __name__ == "__main__":
    mcp.run(transport="http", host="0.0.0.0", port=8000)  # bind so a tunnel can expose it
```
